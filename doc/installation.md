# Installation

## Requirements

- Bash 3.2 or newer
- tmux 2.1 or newer
- [Mike Farah yq](https://github.com/mikefarah/yq) v4 or newer

Check locally:

```bash
bash --version
tmux -V
yq --version
```

`yq` must be Mike Farah's Go implementation. The Python package named `yq` is not compatible.

## Install

Install a reviewed release or branch into a user-owned directory:

```bash
mkdir -p ~/bin
curl -fsSL https://raw.githubusercontent.com/mustafamohsen/tmuxify/main/tmuxify -o ~/bin/tmuxify
chmod +x ~/bin/tmuxify
```

Make sure `~/bin` is on `PATH`.

Avoid piping mutable scripts into `sudo`. If you need a system-wide install, use your package manager or an admin-managed path.

## Update

```bash
tmuxify --update
```

The updater checks the candidate's Bash shebang, Bash syntax, and one embedded numeric `major.minor.patch` version. It does not execute the downloaded program for validation. Invalid candidates leave the installation unchanged.

The replacement is staged beside the writable install path and made executable before an atomic rename. A backup preserves the previous version on replacement failure. If automatic restoration also fails, the error reports a retained recovery backup to restore manually. Examples and completions are still refreshed on successful script updates. The updater does not automatically escalate with `sudo`.

These are format and syntax checks, not authenticity checks or a sandbox. For higher assurance, install a reviewed release or pinned commit rather than a mutable branch.

## User config directory

Tmuxify stores user-level files under:

```bash
${XDG_CONFIG_HOME:-$HOME/.config}/tmuxify
```

Important subdirectories:

- `layouts/default.yml` - optional reusable default layout.
- `layouts/examples/` - example layouts refreshed by `tmuxify --update`.
- `completions/` - shell completion files refreshed by `tmuxify --update`.

## Shell completions

Run `tmuxify --update` first so completion files exist.

Bash:

```bash
source "${XDG_CONFIG_HOME:-$HOME/.config}/tmuxify/completions/tmuxify.bash"
```

Zsh, before `compinit`:

```zsh
fpath=("${XDG_CONFIG_HOME:-$HOME/.config}/tmuxify/completions" $fpath)
autoload -Uz compinit && compinit
```

Completion metadata is generated by:

```bash
tmuxify --completion-options
```
